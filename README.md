# Drought — программа станции (v16, версия 1.5)

Без подключения к сайту программа называется **Drought Monitor**. После подключения к сайту
«ПочваМонитор» (функция подписки) она сразу называет себя **ПочваМонитор X Drought** и показывает аналитику по вашим датчикам.

## Что нового в v16
* **Аналитика считается по вашим датчикам.** Программа отправляет показания (температура, влажность,
  вода, и если есть — засолённость, pH, N, P, K, координаты) на сайт, сайт считает по ним и возвращает в раздел
  «Аналитика»: погоду на 7 дней по координатам датчика, прогноз влажности почвы и засоления, риск засухи,
  подбор культур и советы по pH/засолённости/влажности датчика, обеспеченность N, P, K.
  Участки сайта больше не используются. Сверху — выбор датчика.
* **Неполные данные.** Если какого-то датчика нет, прогноз строится по остальным, а вверху раздела видно:
  «Полные данные» / «Неполные данные» / «Недостаточно данных», что измеряется, чего нет и что из-за этого
  не учтено. Без датчика влажности почвы прогноз засухи невозможен — программа так и пишет.
  Датчик, который всё время шлёт 0, считается неподключённым. Без координат погода — средние многолетние.
* **Arduino может передавать дополнительные показатели** (необязательно):
  `температура,влажность,вода[,засолённость,pH,N,P,K]`. Пустое поле — датчика нет.
  Примеры: `27.6,81.0,500` (как раньше), `27.6,81.0,500,,7.9` (есть только pH),
  `27,40,300,5.1,8.0,13,28,296` (всё).
* **Установщик называется Drought** (`Drought_Setup.exe`, программа `Drought.exe`), своя иконка (`icon.ico`)
  у установщика, exe и окна.

## Установка через командную строку (cmd)
1. Распакуйте архив в папку, например C:\drought_station.
2. Откройте cmd в этой папке и выполните:
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   python main.py
3. При первом запуске зарегистрируйтесь. Перед регистрацией нужно принять условия и политику
   конфиденциальности (кнопка «Читать документы»). Текст также в файле LICENSE.txt.

## Что нового в v14
* **Уведомления.** Исправлена ошибка: всплывающее уведомление не закрывалось и мешало выбирать датчики
  (сбой в `_safe_destroy`). Теперь до 3 уведомлений стопкой в правом нижнем углу, каждое исчезает через
  6 секунд, **при наведении мыши сразу скрывается**, есть крестик. Раздел **«Уведомления»** — история всех
  уведомлений с фильтром (засуха / связь / система), счётчиком непрочитанных в меню, переключателями
  «Всплывающие уведомления» и «Звук». Фермер видит уведомления только по своим датчикам.
  Настройки Telegram-бота — в разделе «Telegram-бот».
* **Подписка** (раздел «Подписка», только у эксперта): сравнение бесплатного тарифа и подписки,
  7-дневный пробный период (один раз на аккаунт), кнопка «Оформить подписку» — оплата пока не подключена,
  ничего не списывается (файл `payments.py`). Администратор может выдать Pro вручную: «Все пользователи».
  Фермеры автоматически работают по тарифу своего эксперта, им подписка не предлагается.
* **Устройства**: этот компьютер, программы на аккаунте сайта (с деактивацией), датчики Arduino
  (активировать / деактивировать).
* **Аналитика с сайта**: сводка датчиков, погода на 7 дней, прогноз влажности почвы, предупреждения,
  что лучше посадить, советы по почве и погоде. Участки сайта сортируются по расстоянию до датчиков.
  Без сети показываются последние полученные данные (`analytics_cache.json`).

## Тарифы (значения — в `plans.py`)
| | Бесплатно | Подписка / пробный период |
|---|---|---|
| История датчиков | 7 дней | любой период (хранится 90 дней) |
| Экспорт в Excel | 7 дней | 30 дней |
| Фермеры | до 3 | без ограничений, получают тариф эксперта |
| Подключение к сайту по коду, отправка по API и в JSON-файл | — | ✓ |
| Аналитика сайта, устройства аккаунта | — | ✓ |

Отправка на сайт зависит от тарифа того, кто подключил программу. Когда пробный период заканчивается,
отправка и аналитика приостанавливаются, данные не удаляются.

## Подключение к сайту
Сайт → раздел «ПочваМонитор X Drought» → «Создать код подключения» (нужен вход на сайт).
В программе: Настройки → Подключение к сайту → адрес и код → Подключить.
Если устройство отключить на сайте или в разделе «Устройства», программа сама перестанет отправлять данные.

## Установщик .exe (Drought_Setup.exe)
Собрать установщик — один двойной щелчок по **build_installer.bat** (нужны Python 3.10+ и интернет):
1. Скрипт сам создаёт окружение, ставит библиотеки и PyInstaller и собирает `dist\Drought\Drought.exe` —
   программа запускается **без окна консоли**.
2. Затем упаковывает всё через Inno Setup 6 (если его нет, предложит поставить через winget)
   в `installer_output\Drought_Setup.exe` и откроет эту папку.

Что делает установщик «Drought»:
* показывает **пользовательское соглашение** (`installer\license_ru.txt`) — без «Я принимаю» дальше не пустит;
* ставит программу в папку пользователя, права администратора не нужны;
* создаёт ярлыки **Drought** в меню «Пуск» и (по галочке) на рабочем столе, плюс «Удалить Drought»;
* после установки может сразу запустить программу.

Данные (база показаний, настройки, кэш аналитики) у установленной программы лежат в `%LOCALAPPDATA%\Drought`
и не удаляются при удалении или обновлении программы. При запуске из исходников (`python main.py`) — рядом с main.py, как раньше.

Готовый `Drought_Setup.exe` положите в папку `downloads` сайта — сайт сам начнёт его отдавать.
Файл не подписан цифровой подписью, поэтому Windows SmartScreen при первом запуске может показать
«Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
